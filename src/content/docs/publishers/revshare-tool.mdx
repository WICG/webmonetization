Probabilistic revenue sharing (revshare) is a way to share a portion of a web monetized page's earnings between multiple recipients.

The <LinkOut href="https://webmonetization.org/tools/prob-revshare">probabalistic revshare generator</LinkOut> allows you to define a list of recipient wallet addresses and assign each one a percentage of the revenue. Each time the page loads, a recipient's chance of being chosen equals their percentage, so over time they receive about that share of the page's revenue. The percentages must add up to 100%.

## Create a new revshare configuration

The revshare generator creates a link tag with a URL that's hosted on webmonetization.org. If you'd rather use a script that you host yourself, check out the [revshare tutorial](/tutorials/revenue-sharing).

1. Enter the first two recipients' wallet addresses. Each recipient starts at 50%, and a recipient's percentage can be edited once their wallet address is valid. A Web Monetization link tag is generated automatically.<br /><img src="/img/docs/pubtools/revshare-two.png" alt="Revshare generator with two wallet addresses, each assigned 50%" class='img-outline' style="max-width: 90%" />
2. Click **Add recipient** if you have more wallet addresses to add. A new recipient starts without a percentage.
3. Adjust the percentages so that they add up to 100%. Each percentage must be greater than 0 and can have up to two decimal places. As long as the wallet addresses are valid and the total is 100%, a new Web Monetization link tag is created each time you make a change.<br /><img src="/img/docs/pubtools/revshare-three.png" alt="Revshare generator with three wallet addresses assigned 50%, 25%, and 25%" class='img-outline' style="max-width: 90%" />
4. When you're finished, copy the link tag and place it on your HTML page.

## Change an existing revshare configuration

1. Click **Import**.<br /><img src="/img/docs/pubtools/revshare-blank.png" alt="Revshare generator with no information filled in and the import button in the bottom right corner" class='img-outline' style="max-width: 90%" />
2. Enter the Web Monetization link tag that references your revshare configuration.<br /><img src="/img/docs/pubtools/revshare-import.png" alt="Import existing revshare config screen with a test link tag entered and the import revshare button active" style="max-width:50%" class='img-outline' />
3. Click **Import revshare**, then make your changes. Each change you make will result in a new link tag. Link tags created when the generator used weights are converted to percentages on import, keeping the same split (for example, weights of 2, 1, and 1 become 50%, 25%, and 25%).<br /><img src="/img/docs/pubtools/revshare-three.png" alt="Revshare generator with three wallet addresses assigned 50%, 25%, and 25%" class='img-outline' style="max-width: 90%" />
4. When you're finished, copy the new link tag and place it on your HTML page.
